# RC 재료 — 배근 전 탄성 해석

모델링의 Properties → MATERIAL에서 Category를 **RC**로 선택한다.
콘크리트 강도, 주철근 강종, 띠철근·스터럽 강종을 각각 내장 DB에서 선택할 수 있다.
콘크리트 선택 시 DB의 적용 가능한 E·포아송비·단위중량을 기존 단위 변환 규칙으로
입력한다. 주철근과 띠철근 강도는 MPa로 표시한다.

현재 값을 선택 부재에 적용하거나, 물성 이름을 지정하여 저장한 뒤 Element에서
Material + Section을 선택해 보·기둥을 생성한다. 벽체는 Material + Thickness를
사용한다. 저장된 RC 재료 정보와 부재·벽체 지정 정보는 프로젝트 파일에도 보존된다.

## 해석 범위

- 보·기둥: 콘크리트 E와 기하학적 전단면 A·I·J, G = E / [2(1+ν)]를 사용한다.
- 벽체: 콘크리트 E·ν와 지정 두께를 기존 탄성 쉘 해석에 전달한다.
- 자중은 저장된 단위중량을 기존 자중 설정에 따라 사용한다.
- 철근 강종·공칭 강도는 재료 정보로만 저장한다. 배근량·배치에 따른 강성,
  균열 강성 저감, 철근 항복, 콘크리트 압괴, RC 소성힌지·내력 검토는 포함하지 않는다.
- 구조 계산서 및 배근 입력은 이 기능에 포함되지 않는다.

철근 DB 레코드는 현재 `PENDING / auto_apply=false`이다. 명시적으로 선택한 공칭
값과 검증 상태만 기록하며 DB를 검증 완료로 바꾸거나 해당 강도를 해석에 사용하지 않는다.
배근·재료 비선형 해석을 추가할 때 해당 데이터와 구성모델을 별도로 검증해야 한다.

## 저장 규칙

`rc_*` 속성의 강도는 모델 표시 단위와 무관한 MPa 값이다. 부재의 `E`, `G`,
`density`는 기존 모델 단위다. `rc_analysis_model=gross_elastic`로 해석 가정을
명시하며, 철근 강도를 일반 강재 소성힌지의 `Fy`에 전달하지 않는다.
일반 재료로 교체하면 이전 RC 속성은 제거되고, 단면만 교체하면 RC 정보는 유지된다.
